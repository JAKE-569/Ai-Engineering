# 도면 검토 워크스페이스 개선 설계

## 목표

중복 상단 메뉴를 제거하고 좌측 메뉴 중심으로 통일한다. 도면 검토 화면은 업로드된 실제 PDF/이미지를 중앙에 표시하며, 우측에 AI 검토 근거와 마크업을 보여준다. 원가절감 검토는 업로드 결과를 기반으로 생성하고 세부 산출 내역을 팝업으로 제공한다.

## 설계

- `Header`는 브랜드, 검색, 연결 상태, AI 사용량만 유지하고 페이지 탭 네비게이션을 제거한다.
- `DashboardView`의 선택 도면 영역은 `fileDataUrl`을 `DrawingCanvasPreview`에 전달하고, 데이터가 없는 경우에만 빈 상태를 표시한다. PDF는 기존 `PdfViewerModal` 경로를 재사용한다.
- 검토 결과의 `markups`, `visualFindings`, `ocrBlocks`는 중앙 도면 위 좌표 오버레이와 우측 상세 카드에서 함께 사용한다.
- `CostVeView`는 `veItems`를 우선 사용하고, 업로드 파일의 VE 결과가 없는 경우 고정 예시를 자동 표시하지 않는다. 각 항목은 기존/변경 비용, 절감액, 절감률, 기간 단축, 산출 근거를 표시하며 상세 팝업에서 계산식을 펼친다.
- 모든 변경은 새로고침 시 초기화되는 현재 프로토타입 저장 정책을 유지한다.

## 완료 기준

1. 데스크톱에서 상단 페이지 탭이 보이지 않고 좌측 메뉴만 페이지 이동을 담당한다.
2. 업로드한 PNG/JPG/PDF가 대시보드 도면 영역에 실제 원본으로 표시된다.
3. 도면 검토 결과가 도면 위 마크업 및 우측 근거 영역에 연결된다.
4. 원가절감 화면에서 업로드된 VE 결과를 파일별로 볼 수 있고 세부 내역 팝업이 열린다.
5. `npm run build`와 Vercel Production 빌드가 성공한다.
