# Ai ENG Agent 발표자료 — 현재 구현 기준

갱신: 2026-10-26. 이 문서는 현재 소스와 실제 검증 결과를 설명합니다. docs/superpowers의 문서는 과거 설계 이력이며 구현 완료 증빙이 아닙니다.

## 목적

PDF/이미지 도면의 관찰, 법규 근거와 검토의견을 연결하여 검토자의 재확인을 지원합니다. 지원 공종은 소방·건축·토목·건축기계·건축전기입니다.

## 처리 흐름

PDF 페이지 이미지 변환 → P-GPT Gemini 또는 NVIDIA Vision → 로컬 법규/벡터 검색 → 항목 정규화 → 페이지별·종합 검토 → 주석·보고서 → 프로젝트 폴더 저장.

Gemini는 사내 P-GPT Native API를 SDK로 호출합니다. 운영계 주소는 http://aigpt.posco.net/gpgpta01-gpt, 기본 모델은 gemini-3.5-flash입니다. 사내 UUID 키는 서버에서만 사용합니다. CLI나 Vertex AI ADC를 Gemini 검토 인증으로 사용하지 않습니다.

## 구현과 검증

- PDF/이미지 검토, 설계·안전·VE 분류, 주석·워크스페이스·보고서.
- 부분 실패와 판정 상태를 분리하고 좌표 없는 의견은 목록에 표시.
- 도면과 결과를 local-data/에 저장하고 새로고침·재실행 후 복원.
- 소방 조항 공종 보정, 타 공종 분류, 중복 적재 방지 SQL/스크립트 제공.
- 운영계의 시험용 PNG 이미지 입력 및 JSON 응답 성공 확인.
- 단위/API/저장 테스트 및 Edge 브라우저 시나리오 테스트 수행.

## 시연

새 문서 검토에서 PDF/이미지를 등록합니다. 도면 워크스페이스에서 의견·증거·법규·페이지를 확인합니다. 위치 미확인 의견에는 도면 마커가 없습니다. 일부 페이지가 실패하면 부분 완료로 표시됩니다. 통합 보고서 또는 도면별 PDF 출력을 사용합니다. 새로고침하여 저장 결과가 복원되는지 확인합니다.

## 완료로 설명하지 않을 기능

AI 챗봇은 미구현입니다. 독립 소방 계산 모듈은 미연결이며 검토 결과에 자동 계산을 제공하지 않습니다. 법규 데이터는 소방 발췌·타 공종 요약 중심이며 최신 원문 전체 DB가 아닙니다. DWG/Office 원본 직접 분석, 다중 사용자 서버, Vercel 영구 저장은 이번 구현 범위가 아닙니다.

## 향후 평가

현업 샘플에서 OCR·도면 위치·조문 매칭·오탐·누락을 측정합니다. 법규 원문과 시행일·개정 이력을 확보한 다음 자동 수치 판정의 적용 범위를 확대합니다.
