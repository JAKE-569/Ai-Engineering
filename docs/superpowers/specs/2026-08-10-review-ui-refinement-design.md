# 도면 검토 UI 정리 및 Evidence 연결 설계

## 목표

통합 보고서와 AI 검토 의견을 표 중심으로 정리하고, 도면 확대·축소 및 주석 선택 시 근거 카드와 도면 위치를 안정적으로 연결한다.

## 설계

1. `ReportView`는 요약·설계·안전·원가·VE를 한 페이지 흐름으로 구성하고 print 전용 CSS에서 A4 1페이지에 맞춘다.
2. `DashboardView`의 서술형 `reviewNarrative`는 행 기반 표로 렌더링한다. 긴 문장은 셀 안에서 자연스럽게 줄바꿈하며 한글 단어 중간 분리를 막는다.
3. `DrawingCanvasPreview`는 PDF/이미지 도면과 마크업을 동일한 transform 컨테이너에 넣고, Ctrl+휠 및 버튼 줌을 도면 기준으로 처리한다.
4. 주석 선택 상태를 `ReviewWorkspaceModal`과 캔버스가 공유한다. 선택 주석의 정규화 좌표에서 가까운 위치에 상세 카드를 배치하고 SVG path로 연결한다.
5. `Evidence`는 markup의 법규 코드로 `fireRulesFullDb.json`을 조회해 조문 원문·출처·조항을 표시한다. 조문을 찾지 못하면 추정 문구를 만들지 않고 확인 필요 상태로 표시한다.

## 검증 기준

- 보고서 본문과 인쇄 미리보기가 1페이지 레이아웃으로 유지된다.
- AI 검토 의견에 표 헤더와 상태 배지가 표시된다.
- Ctrl+휠이 페이지 전체가 아닌 도면 영역만 확대·축소한다.
- 주석 선택 시 상세 카드와 연결선이 같은 도면 위치를 가리킨다.
- Evidence에 실제 DB 조문 원문과 출처 링크가 표시된다.
