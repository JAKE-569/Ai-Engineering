# 전문가 수준 도면 검토 설계

## 목표

페이지별 시각 판독 결과와 도면 세트 종합 판단을 분리하고, 설계·법규/안전·수치·시공성·VE 의견을 근거 중심의 구조화된 결과로 제공한다.

## 설계

1. 업로드된 PDF는 기존처럼 페이지별 이미지로 렌더링하되, 페이지 분석 결과를 파일 단위로 누적한다.
2. 좌표가 없는 서술형 체크리스트는 도면 주석으로 만들지 않는다. 주석은 AI가 실제로 반환한 좌표가 있는 finding만 사용한다.
3. 페이지별 결과는 설계 검토, 안전/법규, 시공·역무, VE 분야로 분리해 대시보드 카드에 표시한다.
4. 각 결과는 상태, 도면 증거, 기준, 기술 판단, 권고 조치, 확인 주체를 포함한다.
5. 계산값이 없거나 도면에서 확인할 수 없는 항목은 PASS 대신 NEEDS_CONFIRMATION으로 표시한다.

## 품질 기준

- 일반 예시 문구를 업로드 도면의 증거처럼 출력하지 않는다.
- 좌표는 0~100%로 제한하고, 실제 좌표가 없는 의견에는 마커를 생성하지 않는다.
- 여러 페이지의 주석 ID는 페이지별로 고유해야 한다.
- 빌드가 성공해야 하며, AI 응답이 JSON 계약을 벗어나면 사용자에게 실패 상태를 표시한다.
