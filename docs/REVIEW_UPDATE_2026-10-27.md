# 검토의견·주석·출도 개선 (2026-10-27)

## 사용자 동작

- 적절·OK·올바르게 등의 긍정 의견: 적절 / 파랑. 확인 필요: 주의 / 주황. 법규 상충·허용치 초과·최소치 미달·한계 근접: 심각 / 빨강.
- 같은 의견에 위반 또는 추가 확인이 명시되면 긍정 표현보다 우선합니다. 최대 기준보다 낮아 기준을 충족하는 경우는 최소치 미달과 구분합니다.
- 저장된 의견도 화면에 불러올 때 재분류합니다. 실제 local-data를 일괄 수정하거나 AI 분석을 다시 실행하지 않습니다.
- 주석 위치를 연결된 시각 분석·OCR 결과에서 복원합니다. 유일한 위치를 확인할 수 없으면 좌표를 만들지 않습니다. 의견 선택 → 주석 위치 지정 → 해당 페이지 도면 클릭으로 저장할 수 있고, 위치 수정도 가능합니다.
- 통합보고서 및 보고서 PDF는 주의·심각만 표시합니다. 전체 일괄 Confirm → 전체 Confirm 해제 토글을 지원합니다.
- 모든 의견이 적절인 경우에는 각 문서의 분석이 정상 완료되고 의견이 하나 이상 있을 때 자동 Approved입니다. 빈 검토·실패한 검토만으로는 자동 승인되지 않습니다.
- Approved 출도는 원본 PDF/이미지를 모아 각 페이지에 Approved 워터마크만 추가한 PDF를 엽니다. 검토보고서·검토의견·AI 주석은 추가하지 않습니다. PDF 원본 크기·회전·벡터·텍스트를 유지하며 원본 파일 자체는 변경하지 않습니다.
- 원본이 없거나 읽을 수 없으면 파일별 오류를 표시합니다. DRM 해제 기능은 포함하지 않습니다.

## 확인 상태 호환

심각도를 확인 기록의 비교 항목에 포함했습니다. 기존 Confirm 기록 또는 의견 내용·분류가 달라진 항목은 재확인이 필요할 수 있습니다. 위치 지정은 의견 내용의 확인 상태를 바꾸지 않습니다.

## 검증

TypeScript, 단위·API 테스트 15개, Edge 브라우저 시나리오 2개로 분류 우선순위·좌표 복원/수동 저장·보고서 필터·Confirm 해제와 복원·출도 PDF 원본 페이지 및 워터마크·검토의견 제외를 검사합니다. 테스트는 임시 저장소와 모의 AI를 사용합니다. 실제 사용자 도면의 AI 판독 정확도를 검증한 결과는 아닙니다.

시각 검토용 합성 도면: [Approved PDF](ui-preview/approved-drawings.pdf), [미리보기](ui-preview/approved-drawing.png).

## 출도 도장 변경

중앙 대각선 워터마크를 우측 하단 빨간 이중 원형 도장으로 교체했습니다. 상단 Approved, 구분선, 하단 출도 날짜(한국 시간 YYYY.MM.DD)를 표시합니다. 도장 지름은 최대 약 36mm이며 작은 페이지에서는 비례 축소합니다. 원본을 덮는 배경 채움은 넣지 않습니다. 출도하는 모든 페이지에 같은 날짜를 사용합니다.

0·90·180·270도 회전과 CropBox가 적용된 PDF에서 도장 위치·문자 방향·날짜 표시, 원본 내용 보존과 검토의견 제외를 검사했습니다. 타입 검사, 단위/API 15개, Edge 브라우저 2개, 빌드가 통과했습니다.

최신 합성 도면: [원형 도장 PDF](ui-preview/approved-seal-drawings.pdf), [미리보기](ui-preview/approved-seal-1.png).
